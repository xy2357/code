# 电子斗蛐蛐：流派、英雄与四人匹配设计

## 四人比赛规则

1. 玩家选择一名英雄进入匹配。
2. 四名玩家组成房间；等待超过 1.5 秒时由机器人补位。
3. 所有存活玩家每轮进行一次三选一构筑。
4. 系统按房间种子将玩家两两配对，客户端播放确定性的自动战斗。
5. 败者损失 1 点生命，初始生命为 10。
6. 淘汰持续到只剩最后一名玩家。
7. 奇数名玩家存活时，其中一名获得轮空且不损失生命。

选牌池会至少提供一张英雄所属流派的强化，其余位置允许出现其他流派，以便玩家追求纯流派或跨流派组合。

## 六个流派

### 普攻流

核心是提高攻击频率与单次普攻收益，通过攻击次数触发额外效果。

- 校准枪膛：普攻伤害提高。
- 高速轴承：攻击速度提高。
- 重型撞针：攻击和防御提高。
- 双重连段：每 5 次普攻追加两段伤害。
- 雷霆连击：每 3 次普攻追加雷电伤害。
- 血能回路：造成伤害时回复生命。

### 暴击流

核心是暴击概率、暴击倍率和暴击后的二次触发，爆发高但生存较弱。

- 弱点扫描：提高暴击率。
- 致命校准：提高暴击伤害。
- 玻璃锋刃：牺牲生命换取攻击。
- 猎杀节奏：同时提高暴击和攻速。
- 暴击追猎：暴击后追加一次伤害。
- 顶点捕食者：同时提高攻击与暴击伤害。

### 大招流

核心是能量获取、大招倍率和能量返还，形成更频繁的技能周期。

- 高容电池：提高能量获取。
- 奥能增幅：提高大招伤害。
- 蓄能甲壳：提高生命和能量获取。
- 聚焦透镜：大招伤害与暴击率同时提高。
- 奥能回响：释放大招后返还能量。
- 无限引擎：同时提高能量获取与大招伤害。

### 闪避流

核心是规避伤害，并把闪避事件转化为反击与能量收益。闪避率存在 70% 战斗上限。

- 相位偏移：提高闪避率。
- 轻盈步伐：提高闪避与攻速。
- 流体装甲：提高闪避与生命。
- 借力打力：提高反击伤害。
- 闪避反击：闪避后攻击本次攻击者。
- 概率悖论：同时提高闪避和反击倍率。

### 冰霜流

攻击累积寒霜；达到 6 层时冻结 0.9 秒并触发寒霜碎裂。未冻结前，寒霜也会逐层降低敌人的攻击频率。

- 低温核心：提高寒霜叠加效率。
- 永冻甲片：提高生命与防御。
- 碎冰节奏：提高攻速与寒霜效率。
- 冰锥弹头：提高攻击和大招伤害。
- 寒潮附刃：每 2 次普攻叠加寒霜。
- 极寒王冠：大幅提高寒霜效率和防御。

### 燃烧流

灼烧持续造成伤害，可并存多组；部分大招会将剩余灼烧一次性引爆。

- 高温燃料：提高灼烧伤害。
- 炽热血液：提高攻击与灼烧。
- 助燃风箱：提高攻速与灼烧。
- 熔岩甲壳：提高生命与防御。
- 余烬印记：周期性施加灼烧。
- 无尽炼狱：提高灼烧和大招伤害。

## 服务端边界

当前服务端负责排队、机器人补位、房间种子、轮次、选牌就绪、对手分配、生命、淘汰和排名。房间使用短令牌验证玩家身份，数据保存在内存中。

这是适合本机、局域网和玩法验证的垂直切片。正式公网部署前仍需：

- 把纯战斗核心提取为客户端与服务端共用的 .NET 程序集，由服务端权威复算；
- Redis 房间状态与 PostgreSQL 账号、战绩持久化；
- 正式登录鉴权、断线重连和幂等请求；
- 多实例服务发现、匹配分区和房间迁移；
- 限流、日志、指标、告警与反作弊审计。

## 初始平衡验证

编辑器菜单 `DQQ/Run Six-School Balance Smoke Test` 会进行 240 场固定构筑交叉对战。当前烟雾测试结果为：

```text
齿轮斗士 70.0%
猩红猎手 68.8%
星核术士 33.8%
幻影行者 57.5%
极地守卫 40.0%
焚心女王 30.0%
```

这不是最终平衡结论，只用于排除技能不触发、触发链失控以及英雄胜率极端异常。正式平衡需要按同构筑镜像、卡牌出现率、不同轮次和玩家真实选牌分布继续分层统计。
