# 二十一点 · 骰子对决（Unity）

Unity 6000.2.14f1 制作的竖屏双骰小游戏。网页版仍保留在父目录中。

## 打开与运行

1. 使用 Unity 6000.2.14f1 打开此目录。
2. 打开 `Assets/Scenes/Main.unity`。
3. 点击 Play。

## 操作

- 点击“投骰子”或按空格键：同时投掷两颗骰子。
- 点击“保存点数”或按回车键：保存并进入机器人回合。
- 玩家或机器人超过 21 时立即爆骰。
- 机器人在不超过 21 且严格大于玩家时获胜；同点会继续投。
